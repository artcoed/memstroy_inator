# Следующие шаги для запуска

## Что сделано

✅ Добавлена автоматическая очистка старых клипов при старте сервера
✅ Добавлен endpoint `/api/cleanup` для ручной очистки
✅ Код скомпилирован и готов к деплою

## Что нужно сделать

### 1. Задеплоить на Railway

```bash
# Закоммитить изменения
git add .
git commit -m "Add auto-cleanup on startup"
git push
```

Railway автоматически пересоберёт и перезапустит сервер.

### 2. Проверить что сервер запустился

После деплоя проверь логи в Railway. Должно быть:

```
Running startup cleanup to free disk space...
Startup cleanup complete deleted_files=XXX freed_mb=XXX
indexed count=0
Server listening on 0.0.0.0:XXXX
```

### 3. Запустить инgest с Telegram

```bash
curl -X POST https://web-production-00687.up.railway.app/api/ingest/tg \
  -H "Content-Type: application/json" \
  -d '{"channel": "MELLSTROYfonz", "limit": 30}'
```

**ВАЖНО**: Начни с `limit: 30` (не 100), чтобы не заполнить диск сразу.

### 4. Проверить что клипы появились

```bash
curl https://web-production-00687.up.railway.app/api/assets?kind=clip&limit=10
```

Должен вернуть список клипов с `id`, `label`, `preview_url`.

### 5. Запустить GUI локально

GUI автоматически:
- Подключится к `https://web-production-00687.up.railway.app`
- Скачает метаданные (txt + thumbnails) в `~/.memstroy/cache/clips/`
- Покажет превью с названиями
- При перетаскивании на холст скачает видео

### 6. Если нужно освободить место

Вручную вызвать cleanup:

```bash
curl -X POST https://web-production-00687.up.railway.app/api/cleanup
```

Или просто перезапустить сервер в Railway (автоматически очистит).

## Логика работы с диском (500MB)

1. **Старт сервера**: Удаляет всё → 0 MB используется
2. **Ingest 30 клипов**: ~150-300 MB (5-10 MB на клип)
3. **Ingest ещё 20**: ~250-400 MB
4. **Диск заполнен**: Перезапуск сервера → очистка → новый ingest

Каждый клип занимает:
- Видео: 5-15 MB
- Текст: 1-5 KB
- Превью: 50-200 KB

**Итого**: ~30-50 клипов помещается в 500MB
